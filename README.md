# 🏴‍☠️ Pirate Math Battleship RPG (초등 5학년 2학기 수학 4단원 8차시 교육용 해전 게임)

![Pirate Math Battleship RPG](public/css/pirate.css)

> **초등학교 5학년 2학기 수학 4단원: 소수의 곱셈 [8차시] 곱의 소수점 위치는 어떻게 달라질까요 (수학 98~99쪽, 수익 66~67쪽)** 개념을 학습하고 컴퓨터 해적선과 1:1 두뇌 해전을 펼치는 인터랙티브 교육용 웹 게임입니다.

---

## 🎮 게임 특징

1. **전략적 초기 함선 배치 (Placement Mode)**
   - 4척의 해적 함선(갤리온 4칸, 프리깃 3칸, 브리건틴 3칸, 슬루프 2칸 = 총 12칸)
   - 실시간 고스트 미리보기 (`초록색`: 배치 가능, `빨간색`: 충돌/범위 초과)
   - `R` 키 또는 마우스 우클릭으로 90도 회전
   - 원클릭 `🎲 자동 배치` 및 `초기화` 지원
2. **수학 문제 풀이 & 대포 발사 권한 시스템 (Math-Gated Attack)**
   - 문제를 맞히면 대포가 장전되어 적 해역(A1~H8)을 클릭하여 포격
   - 연속 정답 시 `🔥 COMBO`와 골드/스타 보너스 획득
   - 오답 시 친절한 개념 해설 제공 후 컴퓨터 해적으로 턴 전환
3. **4단계 해역 진행도 (Stage Progression)**
   - ⚓ **1 항구 외곽** → 🪸 **2 산호 해협** → 🌩️ **3 폭풍 해역** → 💀 **4 검은 해골 요새**
   - 적 함선을 1척씩 침몰시킬 때마다 다음 해역으로 전진!
4. **스마트 컴퓨터 AI**
   - 체커보드 탐색 및 명중 시 주변 집중 타격 AI 알고리즘 탑재
5. **풍부한 사운드 & 비주얼 연출**
   - Web Audio API 기반 순수 합성 효과음 (대포 발사, 피격 폭발, 물보라, 정답 차임, 승리 팡파르)

## 📚 수록 단원 및 학습 개념
- **10, 100, 1000을 곱할 때**: 곱하는 수가 10배, 100배, 1000배가 될수록 곱의 소수점이 오른쪽으로 한 자리씩 이동
- **0.1, 0.01, 0.001을 곱할 때**: 곱하는 수가 $\frac{1}{10}$, $\frac{1}{100}$, $\frac{1}{1000}$배가 될수록 곱의 소수점이 왼쪽으로 한 자리씩 이동
- **(소수) × (소수)에서 소수점 위치 규칙**: 두 수의 소수점 아래 자리 수를 더한 값만큼 곱의 소수점 아래 자릿수 결정
- **[보기] 자연수 곱셈 활용 및 빈칸 추론**: 자연수의 곱셈식을 보고 소수점 위치 추론하기
- **문제 은행**: 교과서(98~99p)/수익(66~67p)/활동지/OX 퀴즈 24문항 + 6개 유형 무한 동적 문제 생성기 (전 문항 보기 랜덤 셔플 적용)
